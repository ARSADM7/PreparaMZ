# PreparaMZ — como publicar e vender (custo zero)

## A app
Pasta `app/` — PWA estática, sem servidor. Conteúdo do MVP:
- Matemática 10ª Classe 2024 (1ª Chamada): enunciado completo grátis + resolução passo a passo das 10 perguntas (soma das cotações: 20 valores)
- Pergunta 1 resolvida é amostra grátis; as restantes abrem com código
- Lista "Em produção": Matemática 2011–2025 (entram por fases)

## Publicar na Vercel (grátis)
1. Cria um projecto novo na Vercel e faz upload da pasta `app/` (ou liga um repositório GitHub com esta pasta).
2. Sem build: é HTML/CSS/JS puro. O endereço fica `preparamz.vercel.app` (ou nome parecido que estiver livre).
3. Testa no teu telemóvel: abrir o link → menu do navegador → "Instalar aplicação".

## Antes de vender: 1 minuto
✅ FEITO (2026-10-24): o número de WhatsApp **258844744484** já está configurado em `app/app.js` (CONFIG) — o botão de compra já aparece na app.

## Vender (manual, sem custos)
1. O aluno paga **50 MT** por transferência M-Pesa/e-Mola para o teu número.
2. Ele envia o comprovativo no WhatsApp.
3. Tu envias-lhe UM código do ficheiro `CODIGOS-PRIVADO.md` (começa com PMZ10-).
4. O aluno escreve o código na app e desbloqueia tudo nesse telemóvel.
- Cada código vendido = risca-o da lista para não venderes o mesmo duas vezes.
- Os códigos em claro NÃO estão na app (só hashes) — quem vir o código-fonte não os descobre.
- Quando os 20 códigos acabarem, pede-me mais: eu gero um lote novo e actualizo a app.
